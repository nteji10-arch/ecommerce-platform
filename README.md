# Ecommerce Platform

A full-stack Ecommerce application built using Django REST Framework and React.

## Features

* User Registration & Login (JWT Authentication)
* Product Listing
* Product Search
* Product Details Page
* Add to Cart
* Remove from Cart
* Place Orders
* Order History
* Responsive Navigation Bar
* Docker Support

## Tech Stack

### Backend

* Python
* Django
* Django REST Framework
* JWT Authentication

### Frontend

* React
* React Router
* Axios

### Database

* SQLite (Current)
* PostgreSQL (Planned)

### DevOps

* Docker
* GitHub

## Installation

### Backend

```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
